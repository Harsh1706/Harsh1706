## Local development

This repo includes a small toolchain to preview and lint the profile README
locally.

### Prerequisites

- [Node.js](https://nodejs.org/) 22+
- npm 10+

### Setup

```bash
npm ci
```

### Preview

Start a local server that renders `README.md` as GitHub-flavored markdown:

```bash
npm run dev
```

Then open <http://localhost:3000>. The page re-reads `README.md` on every
request, so refreshing the browser shows your latest edits.

### Lint

Check the markdown for common issues:

```bash
npm run lint
```
